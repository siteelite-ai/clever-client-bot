## Решение и граница проверки

Заказчик подтвердил: для сценария `customer-dn027b-analogs` минимум **три** аналога обязателен. Оракул `scripts/qa/customer-acceptance-cases-v2.json` не смягчён. Нельзя дополнять ответ до трёх товарами «под заказ», товарами с другим монтажным вырезом либо неподтверждёнными карточками и объявлять приёмку успешной.

Это заключение относится к текущему каталогу и одному точечному запуску закрытого preview; оно не доказывает, что подходящих моделей не бывает в принципе. Исходный код production-функции и виджет не менялись. Временная смена проектного секрета автоматически пересоздала конфигурационные версии функций Supabase — см. ниже.

## Доказательство источника и кандидатов

- Официальная [брошюра Signify](https://www.assets.signify.com/is/content/Signify/Assets/philips-lighting/russia/20200326-tradeline-brochure.pdf), стр. 5, указывает для исходного `DN027B G2 LED6 7W 220-240V D90 RU`, код `929002070102`: **монтажный диаметр 90 мм**, 7 Вт, 600 лм, 4000 K. Код `D90` в названии сам по себе не служит доказательством — здесь есть отдельная таблица производителя.
- Read-only обход живого каталожного proxy: категория `Светильники`, `pagination.total=1314`, страницы 1–7 по 200 строк. Полные ответы и ограниченные к просмотру товары не сохранялись и не выводились; shortlist проверялся отдельно. Этот обход не охватывает другие категории и не является доказательством отсутствия товара вне данной категории.
- [Navigator 14477 в каталоге](https://220volt.kz/catalog/svetotexnika/svetilniki/svetilnik-ndl-p3-7w-840-wh-led-14-477-navigator/): положительный остаток и цена 1354 ₸ в живом API; встраиваемый даунлайт, LED без цоколя с драйвером, 7 Вт, 560 лм, 220 В, IP44, нейтральный свет. [Производитель](https://navigator-light.ru/svetilniki/byitovoe-osveshhenie/vstraivaemyie-napravlennogo-sveta-tipa-downlight/ndl-p3/14477.html) подтверждает 4000 K и **монтажный Ø90 мм**. В API 220volt присутствует только общий `Диаметр, см: 11.3`; монтажный диаметр отсутствует. Поэтому текущий runtime не может доказать его посадку, а старый фильтр 8–10 см ошибочно исключает его по наружному размеру.
- Navigator `94833` при целевом чтении живого API: цена 0, девять строк склада с нулевыми остатками; `94834`: выдача по артикулу пуста. Старые индексированные страницы о наличии расходятся с живыми данными. Ни один не засчитан. MESON 080 имеет Ø80 мм, MESON 105 — Ø105 мм; они не являются прямой заменой под подтверждённое отверстие Ø90 мм.
- Обратный контрпример: у [IEK ДВО 1611](https://www.iek.ru/products/catalog/svetotekhnika/kommercheskoe_osveshchenie/svetilniki_dlya_torgovogo_osveshcheniya/daunlayty_klassicheskie/daunlayty_klassicheskie_1611_1615/svetilnik_svetodiodnyy_dvo_1611_belyy_krug_7vt_4000k_ip20_iek) наружный диаметр около 95 мм, а посадочный — Ø70 мм. Поэтому общий диаметр 8–10 см не только исключает реальные варианты, но и пропускает физически неверные.
- Дополнительная проверка живой категории и первоисточников не дала ещё двух подходящих складских позиций. [Navigator 94899](https://navigator-light.ru/svetilniki/torgovoe-osveshhenie/vstraivaemyie-napravlennogo-sveta-tipa-downlight/ndl-p1/94899.html) имеет посадочный Ø90 мм и числится в продаже, но изготовитель указывает **3000 K**; каталожное «нейтральный» этому противоречит и не может заменять проверку числовой температуры. [Navigator 71375](https://navigator-light.ru/svetilniki/torgovoe-osveshhenie/vstraivaemyie-svetodiodnyie-paneli/nlp-r1/71375.html) имеет вырез Ø115 мм, [Navigator 94454](https://navigator-light.ru/svetilniki/torgovoe-osveshhenie/vstraivaemyie-svetodiodnyie-paneli/nlp-s1/94454.html) — 110×110 мм; корпус GX53 71277 рассчитан на отдельную лампу. Ни один из них не засчитан как прямой аналог.

По доступным проверенным карточкам подтверждён **один перспективный складской кандидат, но ноль кандидатов, которые текущий бот способен доказательно показать как совпадающие по монтажному отверстию**. Три не подтверждены.

## Системный путь, не SKU-патч

1. В нормализованной технической схеме каталога разделить `mounting_cutout_mm` и `outer_diameter_mm`; не использовать общий «Диаметр» как прокси посадочного отверстия. Для отсутствующего поля — проверяемое обогащение из документации производителя с URL, идентификатором артикула и датой, а не догадка по названию. До наличия доказательства товар остаётся предварительным, не прямым аналогом.
2. Изменить структурную проверку **для класса встраиваемых замен**, чтобы подтверждённое посадочное отверстие было жёстким условием, а наружный диаметр — отдельной проверкой перекрытия/габаритов и явной оговоркой. Сохранить жёсткие проверки категории, типа монтажа, LED/цоколя, питания, IP, цены и положительного остатка. Не расширять молча критерии цвета/яркости.
   В изолированной ветке уже реализована opt-in проверка по подтверждённому монтажному вырезу: она не снимает другие структурные ограничения и не меняет старый маршрут. Это локальный код с прошедшими unit/type-check, не опубликованный в production и не доказательство прохождения сценария на живом каталоге.
3. Получить/разместить в доступном каталоге ещё минимум два действительно подходящих складских SKU с положительной ценой и подтверждённым Ø90 мм, либо найти их по проверяемым источникам вне просмотренной категории. Без этого обязательная приёмка в текущем состоянии данных невыполнима — алгоритм не должен создавать товары.
   При обогащении хранить `color_temperature_k` и проверять конфликт с текстовым цветом каталога по документу изготовителя, а не считать «нейтральный» эквивалентом 4000 K. Для размеров нужны тип (круг/квадрат), единицы, URL производителя, артикул, дата и версия доказательства; при противоречии — fail-closed.
4. После данных: точечный preview-тест 3 раза, верификация страниц и артикулов, соседние регрессии других логических веток, затем только PR/production. Сейчас **NO-GO на выпуск как полностью готового продукта**.
