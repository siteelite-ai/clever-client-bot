# Контракт обновления веб-виджета

## Цель

Обычный пользователь должен получать актуальную версию виджета без инкогнито,
очистки кеша и ручной перезагрузки. При этом релиз не должен менять маршрутизацию,
диалоговые слоты или бизнес-логику `widget.js`.

## Схема загрузки

1. Сайт один раз подключает версионированный загрузчик:

   ```html
   <script src="https://clever-client-bot.lovable.app/embed.js?v=2026-09-04-loader-2" async></script>
   ```

2. `embed.js` открывает корневой HTML в специальном bootstrap-режиме внутри
   sandboxed iframe.
3. Lovable отдаёт корневой HTML с `Cache-Control: no-cache, must-revalidate,
   max-age=0`, поэтому браузер ревалидирует bootstrap даже при сохранённом кеше
   статических JS. Отдельные статические `.html` этого заголовка не получают.
4. Bootstrap возвращает content-hash версии через `postMessage`.
5. Загрузчик проверяет окно iframe, одноразовый channel и формат версии, после чего
   подключает `widget.js?v=widget-<content-hash>`.
6. Если iframe запрещён CSP, через 1,8 секунды включается прежний JS-манифест.
   Если недоступны оба источника, используется пятиминутный time-bucket URL.

## Защитные свойства

- iframe имеет только `sandbox="allow-scripts"`, без доступа к storage и cookies;
- bootstrap отправляет сообщение только точному origin родительской страницы;
- загрузчик принимает сообщение только от созданного им iframe и с одноразовым channel;
- принимается только версия формата `widget-[a-f0-9]{16}`;
- все четыре release-артефакта должны содержать один content hash:
  `widget.js`, `widget-version.js`, `widget-version.json`, `index.html`.

## Обязательные проверки релиза

```bash
pnpm qa:widget-contract
pnpm qa:widget-loader
pnpm build
```

`qa:widget-contract` блокирует релиз, если content hash устарел, версии расходятся
или из загрузчика удалены проверки источника, channel, sandbox либо grace period.

## Развёртывание и откат

Для перехода со старого loader-1 нужно один раз заменить URL подключения на
`embed.js?v=2026-09-04-loader-2`. Последующие изменения `widget.js` не требуют
правки сайта: новую версию доставляет HTML-bootstrap.

Откат выполняется публикацией предыдущего проверенного commit и новым уникальным
значением `?v=` у `embed.js`. Это исключает повторное использование проблемного
загрузчика из браузерного кеша.
