# Единицы продажи в точном ценовом подборе — адресная проверка 12.10.2026

## Область изменения

Для запроса с точной составной маркировкой и «самый дешёвый/дорогой» полный каталог по-прежнему проверяется до ценового утверждения. Если у подходящих товаров разные единицы продажи, минимум/максимум вычисляется только внутри одной единицы. Ответ называет выбранную единицу и предлагает проверенные единицы кнопками; нажатие создаёт самостоятельный полный запрос и повторяет доказательство. Цены за метр и упаковку не сравниваются и не пересчитываются без подтверждённой длины упаковки.

Новая общая проверка публичной категории ограничена 8 страницами, 120 карточками, 1 МБ на страницу и 10 с по умолчанию. Она требует одинакового canonical/total, правильной активной страницы, полного числа строк и уникальных ID/URL. Названия проверяются по упорядоченным словам класса и точной маркировке; неоднозначную карточку нельзя молча исключить из доказательства минимума. При неполной выдаче или расхождении данных минимум не подтверждается. Повторная адресная сверка публичного каталога использовала предел 20 с на весь запрос и не обращалась к платному API бота. Локальные Node QA-тесты и Deno-тесты функции были зелёными; массовый платный прогон не проводился.

Production `chat-consultant-v3` остался v450. Менялась только изолированная `chat-consultant-v3-closure-preview`, итог v19 (`bcf135d6f6492f61aa7745caa292b339ac83d82bdbea5735cc4a48f620537bd1`, `verify_jwt=true`). База данных, SQL-миграции, production widget и остальные маршруты не изменялись.
