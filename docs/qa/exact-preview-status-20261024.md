## Что пока не подтверждено

- **Положительная live-приёмка клиентских сценариев не проведена.** Роль `siteelite-ai` — Developer, запись временных Edge Secrets возвращает 403. Старые QA-секреты нельзя читать или предполагать. Требуется Owner/Admin для временного доступа; после этого — бесплатный каталоговый preflight и небольшой набор платных клиентских запросов на v187.
- Запись/удаление Edge Secrets действует на общий проект Supabase с production, даже если тестируется закрытый endpoint; возможна краткая перезагрузка окружения. Перед временным QA-доступом нужны узкий перечень секретов, ограниченный срок, проверка публичных версий и удаление тестовых значений после прогона.
- Публичный сайт и Lovable не обновлялись. Браузерный тест на них сейчас проверяет старый виджет и не является приёмкой PR #132.
- «Публичные функции не менялись» означает только уже развернутое production-состояние. Стек draft PR #119–#132 содержит изменения публичных Edge-функций и `widget.js`, в том числе безусловные изменения V3 и клиентского транспорта. Выключенные по умолчанию флаги admission/integration не изолируют весь будущий релиз; перед ним нужна живая регрессия логических веток.
- Два главных риска будущей публикации: V3 по умолчанию меняет подбор и продолжение диалога, а `widget.js` вместе с V2/search меняет сетевые повторы, тайм-ауты и каталожную обработку. Стек нельзя считать безопасным для одновременного выкатывания только потому, что закрытый preview защищён; нужен поэтапный выпуск с проверкой каждой публичной версии и возможностью возврата.
- Это не итоговая готовность к production: обязательный контракт трёх подтверждённых аналогов DN027B остаётся долгом, полный клиентский прогон и репетиция отката ещё не пройдены.

## Экономный следующий прогон после легального QA-доступа

1. Бесплатно: повторно сверить версии/SHA закрытых и публичных функций, выполнить авторизованный каталоговый preflight и короткие route-only пробы. При первом несоответствии остановиться, не тратить OpenRouter.
2. На точном V3 closure-preview — до восьми платных ходов: Acti9 → «покажи» → чип полюсов → новая тема/кабель; бытовой светильник с датчиком до 4 000 ₸; уличный прожектор с уточнением площади/высоты; ИБП для котла. Проверять не только текст, но и карточки/характеристики, наличие, ссылки, чипы, длительность и код запроса. Остановиться на первом системном сбое.
3. Только после анализа этого короткого прогона выбирать адресные повторы и полную клиентскую матрицу. Положительный smoke не обозначать как полный PASS.
