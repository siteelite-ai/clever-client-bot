## Narrow shared proof boundary

Only the existing mandatory-readiness opt-in, non-replacement selection can
use the new helper, and only after the original category guard rejected a
fresh live discovery. Already active targets, rendered cards, normal accepted
taxonomy, replacement protocols and default-OFF behavior are unchanged.

The helper uses ONLY live «Тип/Вид изделия/товара/продукции» values and the
customer's current selecting span. Conservative request-introducer grammar
recognizes a leading nominal class, then stops before an application clause.
It does not scan past another leading product or manufacture synonyms.

1. Partial literal type head in that selecting position nominates ONLY a
   question with matching real type values, via the established verified
   pending-slot protocol. Even one real option can be confirmed. It does not
   admit a category, execute product search, set a target or show cards.
2. The complete literal live type in that same selecting position is category
   membership evidence. The existing readiness/subject phase must still
   validate and bind exactly that type as a mandatory per-card criterion.
   A model cannot switch it to another type during that phase.
   This proof phase is also required for a bare non-measured literal type;
   category membership alone cannot skip it and proceed straight to search.
3. For a dependent answer, source authority also requires the latest completed
   server-issued readiness slot's facet key to equal this fresh live type key.
   A material/diameter answer, forged history or client slot cannot supply it.
   The caller passes only the completed-server-log result, never browser data.

Examples of the same data-driven rule: live heads «бур», «щит», «LED»,
«компрессор». None appear as special cases in production helper code.
Negative boundary: «кабель для насоса» must not nominate pumps. Neither
«кабель Насос», a negated class, a substring nor a material facet can do so.

the older qualifier/alias handling and the full two-turn fixture failed.

the established readiness/subject phase activates it later. No alias guard was
removed to make the test pass. This matters beyond the reproduced noun.
