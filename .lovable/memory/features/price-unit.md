---
name: Единица измерения цены в карточке
description: ProductRef.unit из характеристики «Единица измерения»; render выводит «Цена: X ₸/м», для «шт» суффикс не показывается
type: feature
---
Проблема: для кабеля цена в каталоге относится к МЕТРУ, карточка выводила просто «309 ₸» — клиент читал это как цену всей позиции.

Решение (data-agnostic, 2026-08-14):
- `search-catalog.ts` → `extractUnit(raw)`: среди `options` ищет характеристику по подписи `«Единица измерения…»` ИЛИ ключу `edinica_izmereniya*`; значение (`м`, `шт`, `компл`) кладётся в `ProductRef.unit`. Нет характеристики → `null`, единица никогда не выдумывается.
- `render.ts` → `formatPriceUnitSuffix(unit)`: `Цена: *309* ₸/м`. Для `шт`/`шт.`/`ед` суффикс НЕ выводится (дефолтное чтение, был бы шум). Единица берётся только из кэша, LLM подставить её не может.
- `render.ts` → складские остатки используют ТУ ЖЕ единицу конкретного товара: `Караганда (4648 м)`, `Алматы (12 шт)`. Если API не отдал unit, показывается только число без выдуманного `шт`.
- `schemas.ts` (промпт, блок «ЕДИНИЦА ИЗМЕРЕНИЯ ЦЕНЫ»): цены сравнивать только между товарами с одинаковой unit; при смешанных единицах в выдаче — предупредить клиента.

Тесты: `price-unit_test.ts` (10). Прогоны: «кабель ВВГ 2*1,5 самый дешевый» → `₸/м`, остатки в `м`; «розетку белую» → цена без суффикса, остатки в `шт`.
