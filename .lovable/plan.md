# Выгрузка базы знаний единым архивом

## Что есть сейчас
- В базе знаний 76 записей: 21 из PDF (~1,6 млн символов текста), 50 из ссылок (url), 5 текстовых.
- Сами исходные PDF-файлы в проекте **не хранятся** — при загрузке сохранялся только извлечённый из них текст. Поэтому вернуть оригинальные PDF нельзя, можно выгрузить их текстовое содержимое.

## Что сделаю
1. Выгружу все записи базы знаний (только чтение, ничего в базе не меняю).
2. Каждую запись сохраню отдельным файлом `.md` с заголовком, типом, датой и источником (для ссылок), разложу по папкам `pdf/`, `url/`, `text/`.
3. Добавлю общий файл-оглавление `index.csv` (название, тип, источник, размер, даты).
4. Соберу всё в один ZIP `knowledge_base_export.zip`, проверю содержимое и положу в Файлы для скачивания.

## Вопрос
Если нужны только PDF — выгружу только папку `pdf/`; по умолчанию выгружаю всё.
